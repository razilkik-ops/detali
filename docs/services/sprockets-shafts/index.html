Контакты производства
Делаете звёздочки для нестандартной цепи?

Да. Для расчёта нужны параметры цепи, чертёж или образец сопрягаемой детали.

Можно повторить изношенный вал?

Да, если по образцу можно достоверно восстановить посадки, длины и функциональные поверхности.

Какие материалы используете?

Материал подбирается по чертежу и условиям работы; допустимую замену обязательно согласуем.
